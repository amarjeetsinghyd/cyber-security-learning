# Cyber Security Learning Roadmap & Checklist

Use this checklist to track daily hands-on progress (1–1.5 hours/day).

## Phase 1: Networking & Linux Basics (Weeks 1–3)
- [ ] Learn TCP/IP, DNS, HTTP/HTTPS request/response headers, status codes, and ports.
- [ ] Complete levels 0–20 of [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) for Linux CLI fluency.
- [ ] Complete [TryHackMe Pre Security](https://tryhackme.com/path/outline/presecurity).
- [ ] Practice basic Bash and Python scripting for log parsing and HTTP inspection.

## Phase 2: Core Security Fundamentals & Tooling (Weeks 4–8)
- [ ] Complete [TryHackMe Cyber Security 101](https://tryhackme.com/path/outline/cybersecurity101).
- [ ] Run all 5 local labs in this repo (`python3 run_all_labs.py`) and read every vulnerable-vs-secure diff.
- [ ] Set up [Kali Linux](https://www.kali.org/get-kali/) (WSL or VM) for isolated local lab practice.
- [ ] Learn how Nmap, Wireshark, and Burp Suite Community Edition work on legal lab targets.

## Phase 3: Web Application Security (Months 3–4)
- [ ] Read the [OWASP Top 10](https://owasp.org/projects/top-ten) and [OWASP Top 10:2025](https://top10.owasp.org/2025/en/).
- [ ] Complete Apprentice & Practitioner labs on [PortSwigger Web Security Academy](https://portswigger.net/web-security) covering:
  - [ ] SQL Injection
  - [ ] Cross-Site Scripting (XSS)
  - [ ] Access Control / IDOR
  - [ ] Authentication & Session Management
  - [ ] Server-Side Request Forgery (SSRF)
- [ ] Complete [TryHackMe Jr Penetration Tester](https://tryhackme.com/path/outline/jrpenetrationtester).

## Phase 4: Real-World Practice & Career Readiness (Months 5–6)
- [ ] Work through skill paths on [Hack The Box Academy](https://academy.hackthebox.com/catalogue/paths).
- [ ] Practice writing clear vulnerability reports (impact, reproduction steps, remediation).
- [ ] Explore legal Vulnerability Disclosure Programs (VDPs) on [HackerOne](https://www.hackerone.com/bug-bounty-programs).
- [ ] Prepare for an entry-level practical certification such as [INE eJPT](https://ine.com/security/certifications/ejpt-certification).
